# เครื่องมือ PDF (pdf-edita)

เว็บแอปแก้ไข PDF แบบไฟล์เดียว (`index.html`) ทำงานในเบราว์เซอร์ทั้งหมด ไม่อัปโหลดไฟล์ไปที่ไหน

- Live: https://pdf-edita.netlify.app
- Deploy: Netlify ต่อกับ repo นี้ — push ไป `main` แล้วขึ้นเว็บอัตโนมัติ

## ฟีเจอร์
ใส่ข้อความ (ดูดเข้าเส้น / ช่องกรอกทีละตัวอักษร) · รูปทรง · ไฮไลต์ · ตราประทับ · วางรูปจากคลิปบอร์ด ·
สลับ/ลบ/แทรก/หมุนหน้า (เลือกหลายหน้าได้) · บีบอัด · พิมพ์ · แปลง JPEG · บันทึกรวมหรือแยกหน้าละไฟล์ · Undo/Redo
